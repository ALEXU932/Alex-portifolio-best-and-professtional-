# 🤖 Kiro AI Assistant - Complete Command Reference

## About Kiro

Kiro is an AI-powered portfolio assistant that helps visitors explore Alex's portfolio and helps Alex manage and improve portfolio content.

## 🎯 For Visitors (Portfolio Exploration)

### Navigation Commands
```
"Show me projects" → Navigate to Projects page
"Go to about page" → Navigate to About page
"Contact information" → Navigate to Contact page
"Take me home" → Navigate to Home page
```

### Information Queries
```
"What are Alex's skills?" → List all technical skills with proficiency
"Tell me about experience" → Show work history and achievements
"Is Alex available?" → Check freelance availability
"Where is Alex based?" → Location and remote work info
"Show e-commerce project" → Details about specific project
```

### Quick Info
```
"What technologies does Alex use?" → Tech stack overview
"How many projects?" → Project count and summary
"Contact details" → Email, phone, location
```
