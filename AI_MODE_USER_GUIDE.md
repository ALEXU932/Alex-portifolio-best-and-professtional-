# 🤖 AI Mode - User Guide

## Overview
AI Mode is an intelligent assistant feature integrated into Alex's portfolio that helps visitors explore the portfolio and helps the portfolio owner manage content.

## How to Activate AI Mode

### Step 1: Click the AI Mode Toggle
- Located in the **top-right corner** of the header (next to Dark Mode toggle)
- Button shows ⚡ icon with "AI Mode" label
- When activated:
  - Button turns **purple/pink gradient**
  - Pulsing indicator appears
  - AI Assistant chat window auto-opens

### Step 2: Interact with Kiro
- A floating chat button appears in the **bottom-right corner**
- Click to open/close the chat window
- Type your questions or commands
- Press Enter or click Send button
