## 📝 To Customize

1. **Add Your CV**: Place `cv.pdf` in the `public` folder
2. **Update Projects**: Edit `src/pages/Projects.jsx`
3. **Change Skills**: Modify `src/pages/About.jsx`
4. **Update Contact Info**: Already set to your details
5. **Adjust Metrics**: Edit `src/components/MetricsSection.jsx`
6. **Change Status**: Modify `src/components/StatusBadge.jsx`
7. **Update Current Work**: Edit `src/components/CurrentlyWorking.jsx`
