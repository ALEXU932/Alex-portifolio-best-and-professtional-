# 🚀 AI Mode - Quick Command Reference

## 🎯 Most Popular Commands

### Navigation (Auto-navigates to page)
| Command | Action |
|---------|--------|
| `Show me projects` | Navigate to Projects page |
| `Go to about` | Navigate to About page |
| `Contact information` | Navigate to Contact page |
| `Go home` | Navigate to Home page |

### Information Queries
| Command | Response |
|---------|----------|
| `What are Alex's skills?` | Complete skills breakdown |
| `Tell me about experience` | Work experience & metrics |
| `Is Alex available?` | Availability status & contact |
| `Where is Alex located?` | Location & remote work info |

### Project Details
| Command | Response |
|---------|----------|
| `Tell me about e-commerce project` | Detailed project info with metrics |
| `What projects are there?` | List all projects with descriptions |
| `Show me the task management app` | Specific project details |

### Portfolio Owner Commands
| Command | Response |
|---------|----------|
| `Summarize my projects` | Overview of all projects with metrics |
| `Improve my About section` | Actionable improvement suggestions |
| `Generate project description` | Guide to create new descriptions |
| `Suggest skills to add` | Skill recommendations |
| `SEO optimization tips` | SEO improvement suggestions |

### Help & Guidance
| Command | Response |
|---------|----------|
| `Help` | Complete command list |
| `What can you do?` | Capabilities overview |
| `Show me commands` | All available commands |

## 💡 Quick Tips

1. **Natural Language**: You don't need exact commands - just ask naturally!
   - ✅ "What can Alex do?"
   - ✅ "Tell me about his skills"
   - ✅ "Is he available for work?"

2. **Quick Actions**: Use the 4 buttons when chat opens for instant info

3. **Auto-Navigation**: Kiro will take you to the right page automatically

4. **Context Aware**: Kiro understands variations of commands
